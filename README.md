# Cassandra Lacroix — Photography Portfolio

Personal photography portfolio site for Cassandra Lacroix, photographer based in Montréal, QC.

## Live site
Deployed via GitHub Pages: https://cassandralacroix.github.io/casswebsite/

## Local preview
Just open `index.html` in a browser.

## Structure
- `index.html` — single-file site (HTML + CSS + JS)
- `images/` — category covers + per-category galleries (travel, music, portraits, brands)
